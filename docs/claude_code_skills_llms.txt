# Claude Code Skills - LLM Context

## Overview
Claude Code Skills are reusable, self-contained modules of instructions, scripts, and resources that extend Claude's capabilities for specialized tasks. Skills dynamically load to improve performance on specific workflows and teach Claude how to complete tasks in a repeatable, organization-specific way.

## Key Concepts

### What are Skills?
Skills are folders containing:
- `SKILL.md` - The main file with YAML frontmatter containing metadata and instructions
- Instructions - Step-by-step guidance on how to complete a task
- Scripts and resources - Custom tools and utilities
- Examples - Real-world use cases and patterns

### How Skills Work
1. Claude loads skills dynamically when relevant to a task
2. Skills provide context-specific instructions and examples
3. Skills can be used across Claude apps, Claude Code, and the API
4. They teach Claude your organization's specific workflows and best practices

## Skill Structure

### SKILL.md Format
```yaml
---
name: skill-identifier
description: Clear description of what this skill does and when to use it
---

# Skill Title

[Instructions and guidelines that Claude will follow]

## Examples
- Example 1
- Example 2

## Guidelines
- Guideline 1
- Guideline 2
```

### Required Frontmatter
- `name` - Unique lowercase identifier (use hyphens for spaces)
- `description` - Complete description of skill purpose and usage

## Using Skills in Claude Code

### Installation
Register the Anthropic skills repository as a plugin marketplace:
```bash
/plugin marketplace add anthropics/skills
```

### Using Skills
1. Skills load automatically when relevant
2. Mention the skill explicitly: "use the pdf skill to extract form fields from path/to/file.pdf"
3. Skills work in Claude Code, Claude.ai (paid plans), and via the Claude API

## Creating Custom Skills

### Basic Steps
1. Create a new folder with your skill name
2. Create `SKILL.md` with proper frontmatter and instructions
3. Add any supporting scripts or resources
4. Test the skill in Claude Code or Claude.ai
5. Share the skill folder for team use

### Best Practices
- Write clear, specific instructions
- Include concrete examples
- Specify when and why to use the skill
- Add guidelines for quality output
- Keep skills focused on specific tasks
- Make skills reusable and composable

## Key Differences from Other Features

### Skills vs Slash Commands
- Slash commands: Quick, reusable prompts stored as markdown files
- Skills: Dynamic, context-aware modules loaded automatically with instructions and resources

### Skills vs MCP Servers
- Skills: Instructions and context for Claude
- MCP Servers: Integration protocols for external tools

### Skills vs Plugins
- Plugins: Collections of commands, skills, MCP servers, and hooks
- Skills: Specific capability modules within plugins
